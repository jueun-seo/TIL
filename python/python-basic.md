## 변수와 타입

변수는 데이터를 담는 상자다. `=`는 오른쪽을 먼저 계산해서 왼쪽에 넣는다는 뜻이다.

```python
age = 25
count = count + 1   # count를 1 늘려서 다시 count에 넣는다
```

| 타입 | 이름 | 예시 |
| --- | --- | --- |
| 정수 | `int` | `25` |
| 실수 | `float` | `3.5` |
| 문자열 | `str` | `'홍길동'` |
| 불리언 | `bool` | `True`, `False` |

- 이름은 영어로, 영문자·숫자·`_`만 쓰고 숫자로 시작할 수 없다
- 대소문자를 구분하므로 소문자 스네이크 케이스(`my_name`)로 통일한다
- `'`와 `"`는 같은 뜻이다. 한 파일에서는 하나로 통일한다 (PEP 8)
- 따옴표가 없으면 변수 이름으로 읽는다. `my_name = 홍길동`은 에러다

## 연산

```python
7 / 2     # 3.5, 나누기는 항상 float
7 // 2    # 3, 몫
7 % 2     # 1, 나머지
point += 2   # point = point + 2 와 같다
```

- 정수와 실수를 섞으면 결과는 실수다
- 우선순위가 헷갈리면 먼저 계산할 부분을 괄호로 묶는다
- 문자열은 `+`로 이어 붙이고 `*`로 반복한다. 문자열과 숫자는 더할 수 없다

## 형변환과 f-string

```python
age_text = '25'
age_text = int(age_text)   # 문자열을 정수로
str(20)                    # 정수를 문자열로
```

- `int()` 안에는 숫자 모양의 데이터만 넣을 수 있다
- `input()`은 무엇을 입력해도 문자열로 받는다

```python
name = '홍길동'
age = 20
f'{name}님은 내년에 {age + 1}살입니다.'
```

- 중괄호 안에는 변수뿐 아니라 계산식도 넣을 수 있다

## 비교 연산과 참/거짓

- `==`는 같은지 묻는 것이고, `=`는 값을 넣는 것이다
- 비교 연산의 결과는 `True`나 `False`다
- `bool()`로 바꾸면 `0`, 빈 문자열 `''`, `None`은 `False`이고 나머지는 `True`다

```python
bool(0), bool(-100)       # False, True
bool(''), bool('  ')      # False, True (공백도 데이터)
```

## 조건문

```python
score = 85

if score >= 90:
    grade = 'A'
elif score >= 80:
    grade = 'B'
else:
    grade = 'C'
```

- 조건 끝에 콜론(`:`)을 붙이고, 실행할 줄은 **들여쓰기 4칸**으로 쓴다
- `elif`와 `else`로는 시작할 수 없고 항상 `if`로 시작한다
- 아직 쓸 코드가 없으면 `pass`를 쓴다
- `and`, `or`, `not`으로 조건을 묶고, `in`, `not in`으로 포함 여부를, `is None`으로 비어 있음을 확인한다
- `20 <= age < 30`처럼 비교를 이어서 쓸 수 있다
- 조건 표현식으로 한 줄에 줄일 수 있지만, 짧은 코드보다 읽기 쉬운 코드가 좋은 코드다

```python
label = '성인' if age >= 20 else '미성년자'
```

### 단축평가

- `and`는 앞이 거짓이면 뒤를 보지 않고 앞의 값을 돌려준다. 앞이 참이면 뒤의 값이 결과다
- `or`는 앞이 참이면 뒤를 보지 않고, 앞이 거짓이면 뒤의 값이 결과다
- 의도와 다르게 동작하면 단축평가를 의심한다

## 반복문

### for와 range

```python
range(5)         # 0, 1, 2, 3, 4
range(1, 6)      # 1 이상 6 미만
range(1, 6, 2)   # 2칸씩

total = 0
for i in range(1, 11):
    total += i
print(total)     # 55
```

- 반복할 수 있는 객체를 이터러블이라고 한다. 문자열도 글자가 나열된 것으로 본다
- 반복 밖에서 `total = 0`으로 시작하고, 반복 안에서 값을 쌓는다

### while, break, continue

```python
money = 10000
count = 0

while money >= 3000:
    money -= 3000
    count += 1
```

- `while`은 조건이 참인 동안 반복한다. 종료 조건이 없으면 무한 루프에 빠진다
- `break`는 반복을 끝내고, `continue`는 남은 코드를 건너뛰고 다음 반복으로 넘어간다
- `enumerate()`는 `(번호, 값)`을 하나씩 준다

```python
for i, ch in enumerate('파이썬'):
    print(i, ch)
```

## 리스트와 튜플

```python
menus = ['라면', '햄버거', '마라탕', '샐러드']
menus[0]       # '라면', 인덱스는 0부터 센다
menus[-1]      # '샐러드', 뒤에서부터 센다
menus[1:3]     # ['햄버거', '마라탕'], 슬라이싱
menus[::-1]    # 거꾸로
```

- 리스트는 **뮤터블**이라 인덱스로 값을 바꿀 수 있다. 문자열과 튜플은 **이뮤터블**이라 바꿀 수 없다
- `sort()`는 원본을 정렬하고, `sorted()`는 정렬한 결과만 돌려주고 원본은 그대로 둔다
- `max`, `min`, `sum`으로 최댓값, 최솟값, 합계를 구한다
- 메서드는 외우지 않고, 변수 뒤에 `.`을 찍고 Tab을 눌러 찾는다

```python
passed = []
for score in [70, 95, 82]:
    if score >= 80:
        passed.append(score)
```

### 튜플

- 소괄호로 만드는 바꿀 수 없는 리스트다. 좌표나 날짜처럼 고정된 값에 쓴다
- 값을 꺼낼 때는 대괄호 `[]`를 쓴다
- 튜플 풀기로 두 변수의 값을 한 줄에 바꿀 수 있다

```python
a, b = b, a
```
