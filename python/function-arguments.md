# 함수의 인수 심화: *, **, 기본값 함정

> 2026-10-27 · 인수를 몇 개든 받는 법과 기본값에 리스트를 쓸 때의 함정

## `*numbers`는 받은 값을 묶음으로 모읍니다

```python
def add_all(*numbers):
    return sum(numbers)

add_all(10, 20)        # 30
add_all(1, 2, 3, 4)    # 10
```

`print`는 인수를 몇 개 넣어도 됐는데 `greet`는 2개까지만 받아서 이유가 궁금했습니다. 그 차이가 이 `*`였습니다. 매개변수 이름 앞에 `*`를 붙이면 값을 몇 개 넣든 다 받습니다. 처음에는 "인수를 모두 나열해서 `sum`으로 더하라는 뜻인 것 같다"고 짐작했는데, 맞는 이해였습니다.

받은 값은 안에서 **하나의 묶음(튜플)**이 됩니다. `add_all(10, 20)`이면 `numbers`는 `(10, 20)`이고, `sum((10, 20))`이 `30`입니다. 처음에는 "`numbers`가 어떤 모양이냐"는 질문이 무슨 뜻인지 몰랐는데, 모양은 "안에 어떻게 담겨 있는지"를 말하는 것이었습니다.

```python
def show(*numbers):
    print(numbers)

show(10, 20)   # (10, 20)
```

## `**info`는 이름표 붙은 값을 딕셔너리로 모읍니다

```python
def make_profile(**info):
    return info

make_profile(name='hong', age=10)
# {'name': 'hong', 'age': 10}
```

별이 한 개(`*numbers`)면 이름 없는 값을 **튜플**로, 두 개(`**info`)면 이름표 붙은 값을 **딕셔너리**로 묶습니다. 처음에는 튜플이 뭔지부터 몰랐습니다. 소괄호 `( )`로 만드는 튜플은 바꿀 수 없는 목록이고, 중괄호 `{ }`로 만드는 딕셔너리는 이름표와 값을 쌍으로 담은 것입니다. 딕셔너리는 번호 대신 이름표로 값을 꺼냅니다. `info['name']`은 `'hong'`, `info['age']`는 `10`입니다.

## 기본값에 리스트를 쓰면 같은 리스트를 계속 씁니다

```python
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item('라면'))   # ['라면']
print(add_item('김밥'))   # ['라면', '김밥']
```

장바구니를 매번 새로 받으니까 두 번째는 `['김밥']`만 나올 줄 알았습니다. 그런데 이걸 어떻게 알 수 있는지도 몰랐습니다. 그리고 "`print`는 `return`이 안 되니까 저장이 안 된다"고 생각했는데, 이 함수는 `return items`로 돌려주고 `print`는 밖에서 보여 주기만 하는 것이었습니다.

알아내는 방법은 두 가지입니다. 직접 실행해 보거나, 한 줄씩 따라가 보는 것입니다.

기본값 `[]`는 함수를 부를 때마다 새로 만들어지는 게 아니라 **`def` 줄을 읽을 때 딱 한 번** 만들어집니다. 레시피 카드에 빈 장바구니가 하나 붙어 있고, 안 넣으면 매번 그 장바구니를 꺼내 쓰는 것과 같습니다. 리스트는 안쪽을 고칠 수 있는(뮤터블) 값이라서 `append`로 넣은 것이 그대로 남습니다. 숫자, 글자, 튜플은 못 바꾸니까 이런 일이 없습니다.

### 해결: 기본값은 `None`으로 두고 안에서 새로 만듭니다

```python
def add_item(item, items=None):
    if items is None:
        items = []         # 이번 호출 전용 새 장바구니
    items.append(item)
    return items

print(add_item('라면'))   # ['라면']
print(add_item('김밥'))   # ['김밥']
```

### 직접 장바구니를 넘기면 원본도 바뀝니다

```python
my_cart = ['빵']
result = add_item('우유', my_cart)

print(result)    # ['빵', '우유']
print(my_cart)   # ['빵', '우유']
```

`my_cart`가 `items` 자리에 들어가니까 `['빵', '우유']`가 될 거라고는 맞게 짐작했습니다. 그런데 돌려받은 값만이 아니라 **`my_cart` 자체도 바뀐다**는 건 몰랐습니다. `items`는 `my_cart`의 복사본이 아니라 **같은 리스트에 붙은 또 하나의 이름표**라서, 한쪽에서 `append`하면 다른 쪽에서도 바뀐 것이 보입니다. 리스트가 뮤터블이라서 생기는 일이고, 기본값에 리스트를 쓰면 같은 장바구니를 계속 쓰게 되는 것도 같은 원리입니다.

### `item`과 `items`는 둘 다 그냥 매개변수입니다

```python
def add_item(item, items):
    items.append(item)
    return items

my_cart = ['빵']
add_item('우유', my_cart)
```

`item`은 물건 하나를, `items`는 장바구니를 받는 칸입니다. `s`가 붙었다고 파이썬이 리스트로 보는 것은 아니고, 사람이 알아보기 쉽게 복수형으로 지은 이름일 뿐입니다. 함수를 부르면 칸에 값이 순서대로 들어갑니다.

```python
item  = '우유'
items = my_cart
```

"이름표"는 함수에서만 쓰는 규칙이 아니라 파이썬의 모든 변수가 그렇게 동작합니다. `item`도 `'우유'`에 붙은 이름표입니다. 다만 글자는 못 바꾸는 값이고 리스트는 안쪽을 고칠 수 있는 값이라서, 이름표가 둘이 되었을 때 같이 바뀌는 문제는 리스트에서만 생깁니다.

### `items`가 리스트인지는 어떻게 알까

`def` 줄만 봐서는 알 수 없었습니다. 파이썬은 칸에 어떤 종류의 값이 올지 정해 두지 않기 때문입니다(동적 타입). 대신 단서를 봅니다.

- 이름: `items`라는 복수형 (보장은 아닙니다)
- 함수 안에서 하는 일: `items.append(...)`는 리스트의 기능입니다
- 부르는 쪽: `my_cart = ['빵']`처럼 대괄호로 만들었습니다

리스트가 아닌 것을 넣으면 실행하다가 에러가 납니다.

```python
add_item('우유', '빵')
# AttributeError: 'str' object has no attribute 'append'
```

"여기엔 리스트가 와야 한다"고 적어 두는 방법이 타입힌트라고 합니다. (`items: list`) 아직 배우는 중입니다.

### 이름표를 붙이는 것과 복사하는 것은 다릅니다

```python
a = ['빵']
b = a              # 같은 장바구니에 이름표 하나 더
b.append('우유')
print(a)           # ['빵', '우유']

a = ['빵']
b = a.copy()       # 장바구니를 새로 하나 더 만들어 복사
b.append('우유')
print(a)           # ['빵']
```

처음에는 `b = a`를 "a를 b에 넣는다"고 이해했습니다. 정확히는 리스트를 넣는 것이 아니라 `a`가 가리키는 장바구니에 `b` 이름표를 하나 더 붙이는 것입니다. 장바구니가 하나면 같이 바뀌고, `copy()`로 복사해서 두 개가 되면 따로 움직입니다. 같이 바뀌어도 되는지, 따로 놀아야 하는지는 쓰는 사람이 정합니다.
